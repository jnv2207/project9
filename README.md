## ⭐⭐⭐Pandas Analyzer & Data Visualization

A menu-driven Sales Data Analysis and Visualization tool built with Pandas, NumPy, Matplotlib and Seaborn. All functionality lives in the SalesDataAnalyzer class (with AdvancedSalesAnalyzer demonstrating inheritance).

## Setup
pip install -r requirements.txt
python generate_data.py      # creates data/sales_data.csv and data/sales_data_2.csv
python sales_analyzer.py     # starts the console menu

## Features

Load CSV with exception handling; explore (head, tail, columns, dtypes, info)
Missing data: display, fill with mean, drop, replace with a value
NumPy: array conversion, indexing, slicing, element-wise maths
DataFrames: concat/merge/join, split by region/product, search, sort, filter, sum/mean/count
Statistics: describe, std, var, quantile, percentiles
Pivot tables, groupby + transform, re-indexing and label renaming
Matplotlib: bar, line, scatter, pie, histogram, stack plot, subplots, legends/titles, save as PNG
Seaborn: heatmap, box plot with custom styling

## Assumptions

Dataset is synthetic (Date, Product, Region, Sales, Profit, Quantity, Year); 3 Profit values are intentionally blank for the cleaning demo.
Combining uses SalesID as the key for merge/join.
Plots are saved to an outputs/ folder.
